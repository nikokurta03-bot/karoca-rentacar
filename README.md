# Karoca Rent A Car

Next.js aplikacija za sezonu od **1.4.2027.**, s planiranom flotom **5 Suzuki Vitara 2026.**

## Razvoj

- `npm ci`
- Postaviti lokalnu okolinu prema `.env.local.example` (ključeve ne spremati u Git).
- `npm run dev -- --hostname 127.0.0.1`
- `npm test`
- `npm run build`

Detalji baze, potvrđeni podaci i preostali uvjeti za objavu: [docs/launch-readiness.md](docs/launch-readiness.md).

Izvorni projekt ostaje u Antigravity mapi; rad nastaviti u ovoj kopiji.
